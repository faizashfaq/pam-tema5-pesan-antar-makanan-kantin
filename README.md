# Pesan Antar Makanan Kantin

Proyek kelompok mata kuliah **Pengembangan Aplikasi Mobile** (Teknik Informatika ITERA), dibuat dengan **Kotlin Multiplatform + Compose Multiplatform**.

## Tema
**Pesan Antar Makanan Kantin** – aplikasi untuk memesan makanan dari kantin kampus dan mengantarkannya ke pemesan.
Fitur platform yang dipakai: **Notifikasi** (misalnya pemberitahuan pesanan diterima, diproses, dan siap diantar).

## Cara Menjalankan
- **Android**: buka proyek di Android Studio, pilih konfigurasi `composeApp`, lalu Run.
- **Desktop**: `./gradlew :composeApp:run` (Windows: `gradlew.bat :composeApp:run`).
